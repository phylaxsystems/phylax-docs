This reference lists Credible Layer contract addresses on Ethereum and Linea mainnet. Use the State Oracle **proxy** address when configuring applications. Implementation addresses identify the code behind a proxy.

Addresses reflect the environment records updated on November 18, 2026. A listed deployment does not establish that enforcement or connected services are active. See [Credible Layer Contracts](./credible-layer-contracts) for contract behavior.
