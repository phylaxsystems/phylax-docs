Ethereum enforcement has two linked paths: preparing assertion policy, and enforcing policies on protected transactions. The interfaces below keep assertion management, block marking, and contract execution distinct.

## Interface Map

```mermaid
flowchart TD
    CLI["pcl / Ethereum platform"] --> Release["Release review"]
    Release --> Manager["Authorized Protocol Manager"]
    Manager -->|"Signed lifecycle action"| SO["State Oracle"]
    SO -->|"L1 events with assignments and creation data"| E["Assertion Enforcer"]
    RPC["Credible RPC"] --> B["Participating builder"]
    B <-->|"Candidate / report"| E
    B -->|"Authorized marker"| CR["Credible Registry"]
    G["Protected operation's guard"] -->|"Current block check"| CR
```

## Responsibilities

| Interface | Responsibility | Coordination |
| --- | --- | --- |
| CLI ↔ Platform API | Authentication, project selection, and releases | Platform and CLI maintainers |
| Authorized manager ↔ State Oracle | Assertion assignments and lifecycle actions | Protocol team and contracts maintainers |
| Enforcer ↔ State Oracle | Index assignments and effective blocks. Prepare assertions from the creation data in L1 registration events. | Enforcer and contracts maintainers |
| Credible RPC → Builder | Route top-level submissions | RPC and builder operators |
| Builder ↔ Enforcer | Supply candidate context and apply assertion results | Builder and enforcer operators |
| Builder → Credible Registry | Mark blocks under the authorized builder policy | Builder and Registry administrators |
| Guard → Credible Registry | Check whether the protected operation may execute | Protocol integrators and contracts maintainers |

See [Trust Model](./trust-model) for the guarantees and assumptions at each interface.

## Product and Protocol Boundaries

The State Oracle controls assertion authority and timing. The Credible Registry records builder authorization and block markers. Guards check the Registry while preserving ordinary protocol checks.

The platform coordinates release review and operation. Registration publishes assertion creation data on Ethereum mainnet.
