<Warning>
An OP Stack integration needs an enforcement design agreed for its sequencer client and transaction paths. The previous Rollup-Boost setup is not a verified implementation guide for a new deployment.
</Warning>

Start with [How to Plan an L2 Integration](./network-integration) to place assertion enforcement inside the sequencer's block-building pipeline. Confirm the client revision, transaction-source coverage, supported assertion specification, and failure policy for the target network.

The previous diagram and setup description are available in [repository history](https://github.com/phylaxsystems/phylax-docs/blob/3e3ca9167feebab92da833fcd8d148f361d29a00/credible/l2-integrations/architecture-op-stack.mdx) for design context. This page preserves the published URL and section bookmarks.
