Install `pcl` to build and test assertions and prepare policy releases.

## Installation

### Install with Homebrew

This path requires a working Homebrew installation and access to the Phylax tap. Install the CLI:

```bash
brew install phylax/pcl/phylax
```

This will install the `pcl` binary.

### Install a specific release

Download the archive matching your system from [PCL 1.9.0 releases](https://github.com/phylaxsystems/pcl/releases/tag/1.9.0), extract it, and place the included `pcl/pcl` binary on your `PATH`.

| Release asset | System |
| --- | --- |
| `pcl-1.9.0-linux-arm64.tar.gz` | Linux ARM64 |
| `pcl-1.9.0-linux-x86_64.tar.gz` | Linux x86-64 |
| `pcl-1.9.0-macos-arm64.tar.gz` | macOS Apple silicon |

This release does not publish native Windows or macOS Intel archives. Homebrew resolves its own package version; check `pcl --version` rather than assuming it matches this page.

## Verifying Installation

To verify that `pcl` is installed correctly, run:

```bash
pcl --version
```

You should see the version number of the installed `pcl` CLI.

If you're looking to add the `credible-std` library to your existing project for writing assertions, see the [credible-std Library Overview](./credible-std-overview) for the package name, stable dependency, and remapping reference.
