## What Happened

QuillAudits’ analysis of the December 2024 incident describes repeated unstaking because `unStake` did not reject an already inactive stake. The issue is reuse of a redeemed stake, not merely bypassing its maturity time. [QuillAudits incident analysis](https://www.quillaudits.com/blog/hack-analysis/vestra-dao-500k-exploit-analysis).

## Attack Mechanism

`unStake` marked a stake inactive after paying it out but did not reject a later call for the same inactive stake. The attacker could therefore reuse a redeemed stake and collect additional payouts. The missing condition was whether the stake was still active, rather than simply whether its maturity time had elapsed.

Checking only the state before the transaction is insufficient when two unstakes occur in one transaction. Both would appear to start from an active stake. The assertion reads the stake immediately before each recorded `unStake(uint8)` call:

1. The first call sees `isActive = true` and may proceed.
2. That call marks the stake inactive.
3. The second call sees `isActive = false` and fails the assertion.

A Solidity interface declares the generated mapping getter as a function; it cannot declare the mapping itself. The returned tuple below preserves the stake fields and reads the final Boolean.

## Assertion Example

```solidity
// SPDX-License-Identifier: MIT
pragma solidity 0.8.29;

import {Assertion} from "credible-std/Assertion.sol";
import {AssertionSpec} from "credible-std/SpecRecorder.sol";
import {PhEvm} from "credible-std/PhEvm.sol";

/// @notice Check the stake immediately before each unStake(uint8) call.
contract VestraActiveStake is Assertion {
    bytes4 constant UNSTAKE = bytes4(keccak256("unStake(uint8)"));
    constructor() { registerAssertionSpec(AssertionSpec.Reshiram); }
    function triggers() external view override { registerTxEndTrigger(this.check.selector); }
    function check() external view {
        address staking = ph.getAssertionAdopter();
        PhEvm.CallInputs[] memory calls = ph.getCallInputs(staking, UNSTAKE);
        for (uint256 i; i < calls.length; ++i) {
            uint8 maturity = abi.decode(calls[i].input, (uint8)); // selector already removed
            (,,,,, bool active) = abi.decode(read(staking,
                abi.encodeWithSignature("stakes(address,uint8)", calls[i].caller, maturity),
                _preCall(calls[i].id)), (uint64, uint256, uint256, uint256, uint64, bool));
            require(active, "Stake already redeemed");
        }
    }

    function read(address target, bytes memory data, PhEvm.ForkId memory fork)
        internal view returns (bytes memory)
    {
        PhEvm.StaticCallResult memory result = ph.staticcallAt(target, data, 500_000, fork);
        require(result.ok, "Snapshot read failed");
        return result.data;
    }
}
```

## What This Check Covers

Confirm the deployed getter ABI and stake-field order. Calls through another staking entry point or another adopter need coverage too. This condition prevents reuse of an inactive stake; maturity, yield arithmetic, and payout amounts are separate policies.
