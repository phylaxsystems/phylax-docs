## What Happened

The investigator’s post-mortem dates the Sonic exploit to March 28, 2025 and describes approximately $700,000 extracted by manipulating the balances used to value Beets LP collateral. Borrowing against the inflated valuation and reversing the manipulation left bad debt. [Vicuna investigator post-mortem](https://d23e.ch/research/vicuna-post-mortem/).

## Attack Mechanism

The lending market accepted Beets LP tokens as collateral and valued them from pool balances. A large swap distorted the composition used by that valuation, temporarily raising the reported collateral value. The attacker borrowed against it and then reversed the manipulation, leaving debt backed by a lower-value position.

A naive sum of reserves multiplied by component prices is sensitive to the reserve mix at the observation point. A useful valuation policy must account for the pool's invariant, share supply, fees, and independently priced components. It must also measure the price consumed by borrowing, not just the value after the attacker restores the pool.

Configure the example's reader/calldata to obtain the LP collateral price and select the lending market's `borrow(uint256)` entry point. The pre-call snapshot then observes the valuation presented to that borrow. The post-call check also catches a lasting change during the operation. A 500-bps limit is an illustrative bound on movement from the transaction-start valuation.

## Assertion Example

```solidity
// SPDX-License-Identifier: MIT
pragma solidity 0.8.29;

import {Assertion} from "credible-std/Assertion.sol";
import {AssertionSpec} from "credible-std/SpecRecorder.sol";
import {PhEvm} from "credible-std/PhEvm.sol";

/// @notice Bound a configured metric before and after every covered operation.
contract CallMetricBounds is Assertion {
    address public immutable reader;
    bytes public query;
    bytes4 public immutable operation;
    uint256 public immutable maximumBps;
    constructor(address reader_, bytes memory query_, bytes4 operation_, uint256 maximumBps_) {
        registerAssertionSpec(AssertionSpec.Reshiram);
        require(reader_ != address(0) && query_.length >= 4, "Invalid reader");
        reader = reader_; query = query_; operation = operation_; maximumBps = maximumBps_;
    }
    function triggers() external view override { registerTxEndTrigger(this.check.selector); }
    function check() external view {
        address target = ph.getAssertionAdopter();
        uint256 start = abi.decode(read(reader, query, _preTx()), (uint256));
        require(start > 0 && start <= type(uint128).max && maximumBps <= 100_000, "Invalid baseline or bound");
        uint256 allowed = start * maximumBps / 10_000;
        PhEvm.CallInputs[] memory calls = ph.getCallInputs(target, operation);
        for (uint256 i; i < calls.length; ++i) {
            within(start, allowed, _preCall(calls[i].id));
            within(start, allowed, _postCall(calls[i].id));
        }
    }
    function within(uint256 start, uint256 allowed, PhEvm.ForkId memory at) internal view {
        uint256 value = abi.decode(read(reader, query, at), (uint256));
        uint256 delta = value >= start ? value - start : start - value;
        require(delta <= allowed, "Metric outside bound");
    }

    function read(address target, bytes memory data, PhEvm.ForkId memory fork)
        internal view returns (bytes memory)
    {
        PhEvm.StaticCallResult memory result = ph.staticcallAt(target, data, 500_000, fork);
        require(result.ok, "Snapshot read failed");
        return result.data;
    }
}
```

## What This Check Covers

A deviation limit is not a fair-LP-pricing formula. Manipulation established before the transaction, alternate borrowing paths, or an unsafe price calculated only inside the call need additional coverage. Stable, weighted and constant-product pools require different valuation models.
