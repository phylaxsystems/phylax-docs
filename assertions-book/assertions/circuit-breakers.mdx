Circuit breakers limit unusual ERC20 balance changes. They can reject a candidate transaction before it settles.

## What they watch

- **Adopter:** The contract protected by the assertion.
- **Token:** The ERC20 balance being watched.
- **Direction:** Tokens entering or leaving the adopter.
- **Time:** Balance changes across blocks and transactions.

## Use them separately or together

Each circuit breaker can enforce its own limit.

Rate of change can be used as an independent trigger. It can also be combined with a cumulative trigger.

| Risk | Circuit breaker |
| --- | --- |
| Too many tokens leave over time | Cumulative outflow |
| Too many tokens enter over time | Cumulative inflow |
| The balance changes too quickly | Rate of change |
| Total flow and flow speed must both be bounded | Cumulative and rate of change |

When triggers are combined, the assertion can reject a transaction when either limit is exceeded.

## Why use a Phylax circuit breaker

An onchain circuit breaker is part of the protocol. Every path that moves value must call it.

A Phylax circuit breaker runs as an assertion before the transaction settles. It watches the actual ERC20 balance change of the adopter.

| | Protocol-integrated circuit breaker | Phylax circuit breaker |
| --- | --- | --- |
| Coverage | Protects paths that call the breaker | Covers any path that changes the watched balance |
| Measurement | Uses the amount supplied by protocol code | Uses the observed balance change |
| Time window | Stores counters or buckets in protocol storage | Keeps rolling buckets outside the protected protocol |
| Protocol code | Adds hooks, state, and audit surface | Adds no breaker code or storage to the protocol |
| User gas | Pays for breaker calls and storage writes | Adds no protocol-side gas for breaker accounting |
| Changes | Requires a protocol upgrade or wrapper | Uses an assertion release without changing protocol code |

Phylax removes breaker plumbing from the protocol without removing enforcement. A transaction that exceeds the policy is rejected before settlement.
