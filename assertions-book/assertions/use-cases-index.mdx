Choose a pattern by the transaction you need to constrain. Each reference describes the measured quantity, configuration, expected outcomes, and coverage limits.

This edition is reviewed against [credible-std at `fe49de6`](https://github.com/phylaxsystems/credible-std/tree/fe49de6dcddb8ea1f77ea2828a0c9d7d5f923db0), dated October 28, 2026. Examples are starting points for a policy tied to your deployed contracts. **A contract with no registered triggers enforces nothing.** The [protocol adapter reference](./protocol-adapters) identifies these quarantined examples.

## Start with a working example

- [Run an ownership policy locally](./run-an-example): execute a permitted operation, reject an ownership change, and verify rollback.
- [Compose an ERC-4626 policy](./vault-policies): combine call-level share-price checks with a rolling outflow cap.
- [Configure a Balancer Vault breaker](./balancer-outflow): select the custody address, token, threshold, and window.
- [Reusable patterns](./reusable-patterns): accounting, call results, account health, oracle gates, configuration, and tiered limits.
- [Protocol adapters](./protocol-adapters): find version-specific implementations and their current restrictions.

| Pattern | Measured property |
| --- | --- |
| [Cumulative outflow](./ass20-erc20-drain) | Net ERC-20 outflow as a fraction of the window's balance baseline |
| [Cumulative inflow](./ass22-erc20-inflow-breaker) | Net ERC-20 inflow against that baseline |
| [Flow rates](./rate-of-change-circuit-breakers) | Peak, latest, and mean rate context during cumulative dispatch |
| [Anomaly-gated policies](./anomaly-gated-policies) | A model trigger plus explicit transaction-effect checks |

[Circuit breaker semantics](./circuit-breakers) explains netting, block buckets, and history reconstruction. Thresholds in these examples illustrate behavior; choose production limits from your protocol's activity and response requirements.

## Protect authority and configuration

| Pattern | Measured property |
| --- | --- |
| [Implementation address lock](./ass01-impl-addr-change) | One proxy implementation slot is unchanged at transaction end |
| [Owner and admin locks](./ass05-ownership-change) | Two configured authority slots are unchanged at transaction end |
| [Accredited caller gate](./ass04-kyc-whitelist) | Covered immediate callers appear in the registry; registry reads need snapshot adaptation |
| [Timelock activation bounds](./ass09-timelock-verification) | Delay is in range when the timelock becomes active |
| [AMM fee allowlist](./ass14-fee-calculations) | Stored fee matches the allowed values for the pool type |
| [Paused balance bound](./ass17-panic-state-validation) | A stored counter cannot increase when the transaction starts paused |

## Check accounting and operation results

| Pattern | Measured property |
| --- | --- |
| [Reserve product floor](./ass06-constant-product) | Product of two recorded reserves does not decrease |
| [Deposit supply delta](./ass08-sum-of-all-positions) | Aggregate increase equals a covered deposit's amount |
| [Borrowed supply bound](./ass19-tokens-borrowed-invariant) | Recorded borrowing does not exceed recorded supply |
| [Lending health factor](./ass07-lending-health-factor) | Selected account's post-call health exceeds a floor; legacy caller selection needs adaptation |
| [Asset and share units](./ass12-erc4626-assets-to-shares) | Raw asset/share comparison, valid only for a specified one-to-one model |
| [Deposit and withdrawal share price](./ass13-erc4626-deposit-withdraw) | Asset-per-share ratio does not decrease across those calls |
| [Harvest balance and share price](./ass18-harvest-increases-balance) | Two stored values do not decrease during a covered harvest |

## Oracle and liquidation examples that need correction

These legacy pages retain their source for comparison and explain the replacement approach. They are not deployment-ready policies.

| Example | Required correction |
| --- | --- |
| [Oracle freshness](./ass10-oracle-validation) | Bind the oracle and timestamp read to the operation's snapshot |
| [TWAP deviation](./ass11-twap-deviation) | Use snapshot reads and an exact scaled comparison |
| [In-transaction oracle changes](./ass28-intra-tx-oracle-deviation) | Observe the price at each relevant call or consumption point |
| [Tick bounds and spacing](./ass15-price-within-ticks) | Apply spacing to initialized ticks, not the current pool tick |
| [Liquidation health improvement](./ass16-liquidation-health-factor) | Read distinct pre- and post-call states and match liquidation semantics |

For production preparation, follow [Ethereum assertion testing](/credible/testing-strategy). The [hack case studies](/assertions-book/previous-hacks/prev-hacks-index) provide historical context rather than proof that an example covers every attack path.
